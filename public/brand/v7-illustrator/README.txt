MixWise wordmark v7 — Illustrator editing kit
=============================================

OPEN THIS FILE in Illustrator (not the large base64 SVG in the parent folder):

  mixwise-wordmark-v7.svg

Keep these PNG files in the SAME folder as the SVG:

  mixwise-wordmark-v7-text-forest.png   (letters, no lime)
  mixwise-lime-period-v7.png            (lime wheel only)
  mixwise-wordmark-v7-forest.png        (flat reference composite)

Layers in the SVG:
  - wordmark-text  = move/recolor the lettering
  - lime-period    = drag between mix/wise, scale, replace

Optional vector lime template:
  mixwise-lime-wheel-vector.svg

If Illustrator still warns about missing links, use File > Place
and place the two PNG layers manually on a 1427 x 298 px artboard.

Note: v7 lettering is raster (PNG), not true vector outlines.
